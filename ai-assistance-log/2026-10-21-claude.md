## 4. User request

Good start, and functionally very extensive. But the UI is way too busy.

Let's make the main content of the page a vertical timeline - from the past (top of page) to the future (bottom of page). The user can vertically scroll through the timeline at their leisure using their scroll wheel or trackpad, but please make it easy for the user to jump to the present moment.

Items running in the background in parallel are shown as a parallel branch in the timeline, conceptually similar to how Git tree charts arrange such parallel working.

The centre of the page is the timeline; pull-open draws on the left and right can be used for various utilities and information inspectors.

Put in some sort of settings/control panel somewhere, where the user can change the colour theme (light, dark, auto), do data import/export (i.e., don't have those right there in the toolbar!) and reset all app settings (i.e., clear out the app's LocalStorage allocation).
