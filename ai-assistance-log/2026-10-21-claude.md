## 1. User request

QDVC Focus is a simple single-page web application (see https://github.com/qdvc-apps/test-management as an example of such a codebase structure) which gives the user a place to track:

**Layout:** a desktop-app window.
* **Toolbar:** a "Since last update" display sits in the middle. It goes amber after 20 minutes and red after an hour, and clicking it checks in without changing anything.
* **Main column:**
  * The **Now** card has the task, its notes, a dark glass clock counting from first start, and the time for this stretch and in total.
  * The **Running in background** lane has an animated striped bar on each task.
  * A **Done** log, grouped by day.
* **Right sidebar:** the **Queue**, with a sunken **Up next** tray above a **Later** list.

The surfaces have gradients, inset wells and bevelled buttons, with no flat fills and no accent stripes on box edges.

**How the main actions work:**
* **Drag and drop:** dragging a task into Up next makes it next. Dragging within Later reorders it. Dropping a task on the Now card starts it.
* **Done, start next** moves on to up next.
* **Send to background** parks the current task with its own timer and starts up next. Background tasks can be brought forward or marked done, and any number can run at once.
* **Edit:** double-click any task.

**Additions you didn't ask for:**
* **Undo** for every change (Ctrl/⌘+Z). Each action's confirmation message has an Undo button.
* A small set of keyboard shortcuts; press `?` to see them.
* Two open tabs stay in sync.
* The import dialog lists any repairs it made to a hand-edited file before you confirm.

`paperwork/STATE-FORMAT.md` documents the YAML format, and `examples/a-working-morning.yaml` is a sample you can import.
